# BEAM 学习工具箱

## 官方文档

- [Elixir 官方文档](https://elixir-lang.org/docs/) — 想确认一种写法或查标准库时，从这里找官方答案。
  - short: Elixir Docs
  - featured: true
- [安装 Elixir](https://elixir-lang.org/install/) — 选择自己的电脑系统，跟着步骤把 Elixir 装好。
  - short: Elixir Install
  - featured: true
- [Erlang/OTP 系统文档](https://www.erlang.org/doc/system/readme.html) — 想知道 OTP 为什么这样工作，可以来读官方的详细说明。
  - short: Erlang Docs
  - featured: true
- [下载 Erlang/OTP](https://www.erlang.org/downloads) — 下载 Erlang/OTP，也能查看新旧版本有什么不同。
  - short: OTP Downloads
  - featured: true

## 教程与课程

- [Elixir School 中文](https://elixirschool.com/zh-hans/) — 用中文再听一遍 Elixir 语法、工具和常见主题。
  - short: Elixir School
  - accent: beam
- [Learn You Some Erlang](https://learnyousomeerlang.com/) — 像读一本故事书那样，慢慢走进 Erlang、并发与 OTP。
  - short: LYSE
  - accent: beam

## 包与工具

- [Hex](https://hex.pm/) — 给项目找现成工具包，并看看它们有哪些版本。
  - short: hex.pm
  - accent: tool
  - featured: true
- [HexDocs](https://hexdocs.pm/) — 找到工具包以后，到这里看看模块和函数该怎么用。
  - short: hexdocs.pm
  - accent: tool
- [Livebook](https://livebook.dev/) — 把文字和 Elixir 代码放在同一页，边读边运行。
  - accent: tool
- [Phoenix](https://www.phoenixframework.org/) — 想用 Elixir 做网页和实时应用时，可以从这里继续。
  - accent: tool

## 社区

- [Elixir Forum](https://elixirforum.com/) — 卡住时先搜一搜，也许已经有人遇到过同样的问题。
  - featured: true
- [Erlang Forums](https://erlangforums.com/) — 看大家怎样讨论 Erlang、OTP、工具和实际使用经验。

## 在线练习

- [Exercism · Elixir](https://exercism.org/tracks/elixir) — 用一道道小题，把模式匹配和递归慢慢练熟。
  - short: Elixir 练习
- [Exercism · Erlang](https://exercism.org/tracks/erlang) — 把熟悉的小题换成 Erlang，再看看另一种写法。
  - short: Erlang 练习
