# IEx 拆课验收

## 改了什么

- 中文第 01 课：[打开 IEx，再退出来](http://127.0.0.1:3000/zh/from-scratch/elixir/start-iex)。只讲进入、提示符和退出，不引入返回值。
- 中文第 02 课：[先让代码说话](http://127.0.0.1:3000/zh/from-scratch/elixir/meet-iex)。保留原有代码与三个交互视图，增加来自第 01 课的回顾题。
- 中文 Elixir 路线共 32 课，后面的课编号顺延。原 slug 和已学标记不变，新课使用独立 slug `start-iex`。
- 目录、前后课链接、总课数、深入页与项目课次引用同步；阶段成员保持不变，课次为 01–10、11–18、19–26、27–32。
- 两课元数据建立 `iex-session`、`prompt` → `return-value` 的前置关系；构建会校验前置概念来自更早课程。
- 英文暂不拆课。新课切换英文时前往英文 Elixir 目录；sitemap 和 alternate 链接不生成不存在的英文新课。

- 这轮没有修改 CSS 或字体层级，复用已确认的手绘看板样式。
- 后续课程核心内容、Erlang、英文课程、知识图谱与三态进度不改。
- 元数据字段结构和进度存储结构不改，不迁移或删除已有完成记录。
- 用户原有 README 修改不动，未提交或发布线上。

## 验证与依据

- 本机 IEx 实跑：启动出现 `iex(1)>`；第一次 Ctrl+C 显示 BREAK；第二次 Ctrl+C 结束 IEx。
- 退出方法和 PowerShell 命令依据已打开核对的 [IEx 官方文档](https://hexdocs.pm/iex/IEx.html#exiting-the-shell)。Windows 的实际终端未在这台 macOS 上运行。
- 新增的两项单元测试覆盖实际课程依赖与语言切换回退。页面测试覆盖新课、课序、总数、旧课链接、sitemap 去重和不存在英文新课的情况。
- 最终生产构建、36 项测试、Lint 和 `git diff --check` 全部通过。
- 浏览器验证 Windows 命令切换、两次退出演示及重置、分级提示与答案、英文目录回退、第 01 → 02 课导航、回顾题与原有代码练习。
- 1280px、390px、320px 下第一课三个视图无整页横向溢出；已检查深色模式。截图在 `output/playwright/start-iex-desktop.png`、`output/playwright/start-iex-practice-mobile.png`、`output/playwright/start-iex-exit-dark.png`。
