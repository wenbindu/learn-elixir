# BEAM Path 手绘课件准则

以用户确认的第 01–03 课为基准。当前适用范围：中文、英文的 Elixir 与 Erlang 从零路线；BEAM 主线、字典、实验和全站导航另行安排。

## 教学顺序

1. 页头只放课号、课名和一个具体问题；不显示课程信息卡、用时卡或「今天先做什么」。
2. 默认直接展示完整短代码和批注。批注回答这个关键词、这一行的作用及改动会造成的影响，不能泛泛解释整门语言。
3. 「先猜」只针对眼前代码；结果在「看运行过程」中揭示，按具体行或执行阶段对照。
4. 「只改一处」给出完整修改后代码，先选预测再展开结果。练习有两级折叠提示、折叠答案和一道间隔回顾题；首课没有更早课程，明确豁免。
5. 课末只保留三条要点、项目贡献、学习状态和深入入口。长示例、术语、边界、历史和参考链接放入深入页，原知识不得删除。

每课 1–2 个核心概念，代码及改写均不超过 10 行，解释只针对本课代码、每段不超过 200 字符。至少有一处需要解释的意外或错误，可以出现在预测或改写练习中。环境必须明确：IEx、erl、文件名、编译命令和必需的输入文件不能让读者猜。输出为示例对照，不能声称网页正在执行本地代码。

## 画布布局

- 短代码用居中纸片、两侧错落批注；较长代码用宽纸片与上下批注，避免把代码挤进窄列。布局由代码与讲解关系决定。
- 所有批注同时可读；禁止退回「代码框＋一列按钮＋单条说明」的后台面板式布局。
- 每条批注标行号，用同色划线和曲线箭头连接实际代码行。点击代码或批注同步突出关系，键盘也能操作。
- 箭头按 DOM 位置计算，字体加载、换行、缩放和切换视图后仍指向正确位置。颜色之外还用行号和文字表达关系。
- 窄屏保留完整代码，再按讲解顺序排列批注；不硬塞三栏，不缩小正文，不允许整页横向溢出。

## 字体与层级

英文 Excalifont、中文小赖 Xiaolai、代码 Comic Shanns 等宽。所有资源本站自托管，保留授权，缺字有系统回退。不要用伪粗体、任意字号或随机旋转制造层级。

## 文案与本地化

- 中文说「你／我们」，英文直接描述动作和现象。先说结果，再解释原因；删除空话、重复和演讲式收尾。
- 新术语第一次出现用一句普通话解释。遵守原有禁用词规则，不写通用「先停十秒」模板。
- 中英文使用同一课程 id、概念 id、教学顺序和交互逻辑；题干、提示、按钮、状态、无障碍标签和深入页均翻译。英语页不夹带中文 UI。
- 英语例子的文字数据可以本地化，必须同步修改代码、输出和练习答案，并验证实际结果。
- Erlang 保留自己的 shell、句点、单次绑定、编译和错误表现，不能只替换 Elixir 页面的语言名。

## 元数据与保留

每课记录核心概念、前置概念、后续复用、项目贡献、完成能力和深入页。前置概念必须在同一路线更早课中作为核心出现，构建时失败要指出课程。跨语言同义概念尽量复用 id，图谱 UI 和三态进度不在本轮顺带扩展。

## 验收与执行

按「准则与数据约定 → 内容 → 展示 → 校验」分步实施，不删除已有课的原始字段，不提交或发布未经请求的版本。

- 全量检查课程覆盖、翻译完整、前置依赖、回顾顺序、行号覆盖和短代码限制。
- 练习与源代码只改一处，结果经过语言运行时验证；环境相关例子准备独立临时目录。
- 检查全部路由和深入页，原完整示例、练习、术语与参考链接仍可访问。
- 浏览器验证长短代码、三个视图、深浅主题、320px 手机及桌面；确认箭头、复制、预测门槛、提示、回顾和语言切换。
- 每次交付说明已改、未改、待确认；不能把「通过渲染测试」写成「所有代码都实跑通过」。
