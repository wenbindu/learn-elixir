## 改了什么

1. 移除本课的大渐变标题卡和纵向五段讲解，把两行代码与批注放进同一张点阵纸画板。
2. 「读代码」用彩色手绘箭头连接 IO、puts、括号、引号和第二行代码，说明各自作用。名字与符号按真实职责解释，没有把 IO、puts 当作语言保留关键字。
3. 「看每行结果」可以逐行选择，看到对应输出，以及打印文字和返回值的区别。
4. 「只改一处」可以保留或去掉 IO.puts。先预测是否出现 :ok，再揭示输出；修改代码时会清空上一次预测与答案。
5. 主线只保留返回值这个核心概念。加法、表达式、文字转大写、嵌套调用与真实拼写报错保留在深入页；没有删除原课知识。
6. 按最新反馈移除页面上的「课程信息」和「今天先做什么」整行。元数据仍保留在内容源文件中供校验使用；三点总结、项目贡献和工具安装入口保留。
7. 本课使用独立 CSS、手绘字体回退、SVG 箭头和原生文字，不依赖 Excalidraw 编辑器或远程字体。代码可选中、复制；窄屏将批注排列在代码下面。

输出区是固定例子的对照演示，不执行任意 Elixir。页面明确说明，可复制到本机 IEx 验证。

## 看板字体层级

三个视图共用同一组字号变量，同类内容不再各设字号。手写字体用于标题和短批注标题，正文使用常规字体，代码使用等宽字体。

| 层级 | 桌面字号 | 用途 |
| --- | --- | --- |
| 视图标题 | 22px | 操作问题，手机为 20px |
| 小标题 | 18px | 批注标题、预测问题、结论和反馈标题 |
| 代码与输出 | 20px | 三个视图保持一致，手机统一为 16–18px |
| 正文 | 16px | 批注说明、结果解释、展开的提示 |
| 控件 | 14px | 视图切换、复制、改写和查看结果按钮 |
| 辅助信息 | 13px | 行号、输出区标签、演示说明 |
