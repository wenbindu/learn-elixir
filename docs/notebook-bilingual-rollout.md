## Unicode 空白补齐

- 用户确认后，统一更新 Erlang 第 26、27、28、29、31 课的双语代码与批注，以及中文深入页的解析、统计和 EUnit 例子。原普通空格样例的三项统计保持不变。
- 分词与两端清理使用同一字符集合：Unicode 分隔符、U+0009–U+000D、U+0085，对应 [Unicode White_Space 属性](https://www.unicode.org/Public/UCD/latest/ucd/PropList.txt) 的 25 个码点。只包含空白的行会被过滤；词间空白仍计入字符数。
- 使用明确字符类，不直接依赖 `\\s`：本机 OTP 29 的 `\\s` 配合 `ucp` 还匹配 U+180E，超出了本项目约定。UTF-8 模式、字符类与分割选项依据 [Erlang re 文档](https://www.erlang.org/doc/apps/stdlib/re.html)。
- U+180E、U+200B、U+FEFF 不作为分词空白；无空白的连续中文也不会被猜成多个词。
- 320／1280px、中英文第 28／31 课、三个视图共 24 组浏览器检查无整页横向溢出。未改样式，未发布 Vercel。
- 完整回归零失败：301 项 Node／网页测试，244 个原例／改写案例，519 个额外检查；其中 Unicode 矩阵包含 2,284 个断言，覆盖所有 25 个空白码点、反例、无效编码、深入页 Parser／Stats 集成与真实 escript。运行时检查仅在 `test:examples` 执行，Vercel 的 `npm run build` 不依赖 Erlang。
